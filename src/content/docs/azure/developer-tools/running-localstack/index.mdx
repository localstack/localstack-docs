Three interfaces manage the emulator lifecycle. All of them run the same container image,
`localstack/localstack-azure`.

<SectionCards
  basePath="azure/developer-tools/running-localstack/"

  customTitles={{
    "localstack-cli": "LocalStack CLI",

Whichever you use, the emulator needs a [licensed Auth Token](/azure/getting-started/auth-token/)
covering Azure and `ACTIVATE_PRO=1`. `lstk` is the recommended path — it handles authentication,
the image pull and the lifecycle in one step, and it proxies the Azure CLI through
[`lstk az`](/azure/connecting/azure-cli/).
