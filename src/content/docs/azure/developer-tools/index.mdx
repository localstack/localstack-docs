## Not yet available for Azure

Several LocalStack developer tools do not currently work against the Azure emulator. They are
listed here so their absence is explicit rather than something you discover by trying:

| Tool | Status |
|---|---|
| LocalStack MCP Server | Does not manage the Azure emulator — its `service` parameter does not accept `azure`. |
| Snapshots / Cloud Pods | Not documented for Azure. `lstk save` / `lstk load` exist but Azure state capture is unverified. |
| App Inspector | Not available for Azure. |
| Chaos Engineering | Not available for Azure. |
| Security Testing (IAM Policy Stream) | Not available for Azure — it is built on a different identity model. |
| Cloud Sandbox (Ephemeral Instances) | Not documented for Azure. |

If you need one of these for Azure, raise it with [Support](/azure/help-support/) so it can be
prioritised.
