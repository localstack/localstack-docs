Point your existing Azure tooling at the LocalStack Azure emulator. In most cases this means
overriding a single endpoint — the emulator speaks the Azure Resource Manager and data-plane
APIs, so the tools themselves are unmodified.

The quickest way in is [`lstk az start-interception`](/azure/connecting/azure-cli/), which
redirects every `az` command to the emulator until you stop it.
