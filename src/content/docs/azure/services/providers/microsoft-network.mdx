Azure networking resources connect and isolate everything else you deploy. This provider covers virtual networks and their subnets, the private endpoints and private DNS zones that keep traffic off the public internet, NAT gateways and public IP addresses for outbound and inbound connectivity, route tables, network interfaces, and Bastion hosts for management access.
