## What is LocalStack?

LocalStack is a cloud service emulator that runs in a single container on your
laptop or in your CI environment. It provides a local, fully functional stand-in
for cloud APIs — including [AWS services](/aws/services/),
[Snowflake](/snowflake/), and [Azure](/azure/) — so you can develop and test
cloud and data applications without connecting to a real cloud account or
incurring cloud costs.

Because LocalStack mirrors real cloud behavior, the same infrastructure code,
SDK calls, and CLI commands you use against the cloud work against LocalStack by
only changing the endpoint. That makes it a drop-in target for local development,
automated tests, and CI pipelines.

## Who is LocalStack for?

LocalStack is built for anyone who develops, tests, or operates cloud
applications and wants a fast, isolated, reproducible environment:

- **Application developers** building on AWS, Snowflake, or Azure who want to
  iterate locally without deploying to the cloud on every change.
- **QA and test engineers** who need integration tests that run deterministically
  in CI, without shared-account flakiness or cleanup.
- **Platform and DevOps engineers** validating infrastructure as code
  (Terraform, CDK, CloudFormation, Pulumi) before it reaches production.
- **Data engineers** developing and testing Snowflake queries and pipelines
  against a local engine.
