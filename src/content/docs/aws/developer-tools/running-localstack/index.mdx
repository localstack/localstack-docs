The pages in this sub-section cover the tools you'll reach for when you want to start, stop, and otherwise manage your LocalStack for AWS emulator. The LocalStack CLI is the long-standing command line entry point and is what most developers use day to day. `lstk` is the next-generation rewrite of the LocalStack CLI in Go, and is on track to replace it as the default. The LocalStack MCP Server exposes the same operations through the Model Context Protocol, which lets AI coding agents drive LocalStack on your behalf using natural language prompts.
