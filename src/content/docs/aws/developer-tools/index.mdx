LocalStack's developer tools build upon the AWS emulator and give developers extra ways to move faster in their daily work. Each tool focuses on a specific part of the inner development loop, from starting and stopping LocalStack, to capturing application state, to inspecting traffic between services, to deliberately injecting failures so you can verify how your code responds.

The pages in this section walk through how to fold each tool into your everyday workflow. You'll find guidance on getting started, common patterns we see teams adopt, and where each tool fits between writing code, running tests, and collaborating with teammates. Adopting these tools is one of the most direct ways to get the full value out of LocalStack.
